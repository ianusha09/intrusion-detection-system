# 🔐 Area-Restricted Intrusion Detection System

A real-time AI-powered intrusion detection system that monitors a restricted area using a webcam. It detects human presence with MediaPipe Pose Estimation and sends SMS alerts via Twilio when an intrusion is confirmed.

## 🚀 Features
- Real-time webcam monitoring
- AI-based pose detection
- Customizable restricted zone
- 3-second intrusion confirmation
- SMS alerts with Twilio
- Cooldown to prevent alert spam

## 🛠️ Tech Stack
Python • OpenCV • MediaPipe • cvzone • NumPy • Twilio

## ▶️ Run

```bash
pip install -r requirements.txt
python main.py
``` 

## 📁 Files

```
main.py      # Detection logic
send.py      # SMS alerts
```
